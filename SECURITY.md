# Security Policy

## Supported versions

Forma is pre-1.0; only the latest `0.x` release is supported.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately via GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(Security → Report a vulnerability), or email **luca.dominici.work@gmail.com**.

We aim to acknowledge reports within 5 business days. Forma runs locally, has no
runtime dependencies, and makes no network calls in its core commands — the
expected surface is small, but reports are welcome.
