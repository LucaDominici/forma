# Forma documentation

A reading map. Start where your question is, not at the top.

## If you are new to the project

1. [`PRD.md`](PRD.md) — what problem this solves, for whom, and the one requirement everything
   else serves.
2. [`docs/architecture/ARCHITECTURE.md`](architecture/ARCHITECTURE.md) — arc42: context, building
   blocks, runtime, deployment, with diagrams.
3. [`DELIVERY.md`](DELIVERY.md) — what is actually built and proven today, and what is not.

## If you are about to change the code

1. [`GLOBAL_INVARIANTS.md`](GLOBAL_INVARIANTS.md) — the rules that do not break, each with its enforcement point
   and what turns red. **Read this first.**
2. [`../AGENTS.md`](../AGENTS.md) — the layout, the working rules, the gates to run.
3. [`../CONTRIBUTING.md`](../CONTRIBUTING.md) — including the rule that nothing in `lib/` may know
   any project's names.

## If you are deciding something

1. [`DESIGN.md`](DESIGN.md) — the choices and, more usefully, the alternatives that were rejected
   and why.
2. [`adr/`](adr/) — architecture decision records, immutable once accepted.
3. [`FEASIBILITY.md`](FEASIBILITY.md) — measured, estimated and unknown, kept strictly apart.

## If you are asking what "finished" means

- [`SCOPE.md`](SCOPE.md) — the closed boundary for the architecture explorer, met and measured at
  v0.10.0.
- [`SCOPE-room.md`](SCOPE-room.md) — the open boundary for the Control Room, which reopens the
  first one for that work only.

Both carry a section stating what they do **not** claim. That section is the most useful part of
either document.

## Generated, not written

- [`docs/architecture/c4-model.json`](architecture/c4-model.json) — Forma's model of itself, produced by
  `forma gen`, kept honest by `forma check` in CI.
- [`docs/architecture/ARCHITECTURE.scaffold.md`](architecture/ARCHITECTURE.scaffold.md) — projected from
  the model by `forma doc`. Do not edit it; edit the model.
- [`demo/`](demo/) — the public demo: Forma applied to a repository that is not Forma.

## The shape of the whole thing

```
one source of truth        docs/architecture/c4-model.json   (generated by gen)
  + overlays               c4-status.json      curated programme state
                           c4-issues.json      gh fact base (written by verify)
                           c4-health.json      dated audit verdicts
                           c4-findings.json    the audit register
  + a manifest             forma.room.json     one portfolio, N programmes
  = N renderings           the C4 explorer, the arc42 document, the Control Room
  + one gate               forma check re-derives every one of them and fails on drift
```

If a document here disagrees with the code, the code is right and the document is a defect. Open an
issue rather than trusting the prose.
